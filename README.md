# Ce`ai Pățit? — ERP Cabinet Psihoterapie

Sistem de management clinic securizat pentru psihologi și terapeuți.

## Caracteristici
- **Securitate Maximă**: Criptare client-side (AES-GCM 256) pentru notele clinice.
- **Conformitate Legală**: Panou de conformitate GDPR, Legea 213/2004, și reglementări CPR.
- **Automatizare**: Integrare cu SmartBill (facturare) și Google Calendar.
- **Anonimizare**: Procese automate de eliminare a datelor PII conform legislației.

## Setup
1. Clonează repository-ul.
2. Configurează `.env.local` cu cheile Supabase și SmartBill.
3. Rulează `npm install`.
4. Rulează `npm run dev`.
